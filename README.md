Digital Thermometer – PCB Design and Simulation

Project Overview

This project involves the design of a two-digit digital thermometer capable of measuring temperatures from 0°C to 99°C. The system uses an LM35 temperature sensor and an ICL7107 analog-to-digital converter with 7-segment displays to display the measured temperature.

Main Features

• Two-digit temperature display (0°C–99°C).
• LM35 temperature sensor.
• ICL7107 analog-to-digital converter and display driver.
• Two 7-segment displays.
• PCB design and hardware implementation.
• Circuit design and simulation using Proteus.

Tools and Components

• Proteus Design Suite
• KiCad
• LM35 temperature sensor
• ICL7107 ADC and display driver
• 7-segment displays
• Electronic components
